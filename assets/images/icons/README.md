# Icon Asset Placeholders

This directory contains placeholder files for the following icons used in the app:

- `google_icon.png`: Google sign-in icon (should be a Google "G" logo)
- `apple_icon.png`: Apple sign-in icon (should be an Apple logo)
- `facebook_icon.png`: Facebook sign-in icon (should be a Facebook "f" logo)
- `hand_wave.png`: Hand wave emoji (👋) used on the welcome screen

**IMPORTANT:** Please replace these placeholder text files with actual image files in PNG format before running the app. The current files are just placeholders and will cause image loading errors in the app.

## Recommended Icon Specifications

- **Google Icon**: 56x56px or larger (displayed at 28px)
- **Apple Icon**: 68x68px or larger (displayed at 34px)
- **Facebook Icon**: 68x68px or larger (displayed at 34px)
- **Hand Wave Emoji**: 40x40px or larger (displayed at emoji font size)
- All images should have transparent backgrounds
- PNG format is preferred
